# moNa2 PAW3222 ZMK Firmware

ZMK firmware configuration for **moNa2: Right-Hand Trackball Version**.

This version uses the **PAW3222** optical sensor for trackball input.

## Features

- ZMK firmware
- 42 keys
- Low-profile design
- Fully wireless
- 17 mm key pitch
- 25 mm trackball
- LED indicators
- Rear magnets
- PAW3222 trackball sensor

## Keymap

![moNa2 keymap](keymap-drawer/mona2.svg)

The keymap diagram is automatically regenerated by
[keymap-drawer](https://github.com/caksoylar/keymap-drawer) whenever the keymap
or its drawing configuration changes.

## キーマップ同期

`config/mona2.keymap` は自動生成ファイル。マスターは
[dgarai/zmk-config-moNa2-v2](https://github.com/dgarai/zmk-config-moNa2-v2) の
`config/mona2.keymap`。**キーマップを変えたいときはマスターを編集する。**
このリポジトリを編集しても次の同期で上書きされる。

詳細と元に戻す手順は [KEYMAP-SYNC.md](KEYMAP-SYNC.md) を参照。
